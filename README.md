# Lincoln Space Invaders

**Abraham Lincoln: Vampire Hunter - Space Techno Edition**

A single-file HTML5 canvas game featuring Abraham Lincoln as a space-faring vampire hunter, complete with:

- Procedural space-techno soundtrack
- Flying Cosmic Unicorn special (15s invincibility + tri-beam)
- Temporary special weapons from crates (Grenade Launcher, Napalm, Tesla, Cluster Bazooka)
- Permanent weapon upgrades at checkpoints
- Touch controls, keyboard, and Xbox controller support
- Caricature politician vampire enemies

Originally generated via Gemini Canvas.

Source share: https://share.gemini.google/uZWofLnGCqfO

## Play

Open `index.html` in any modern browser (desktop or mobile landscape recommended).

## Controls

- **Left stick / WASD**: Move & fly
- **A / Space**: Jump / double jump
- **X / Z**: Shoot
- **B / Shift**: Roll
- **Y / E**: Summon Flying Unicorn (when ready)
